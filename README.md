## 🇬🇧 English

TimeListe Generator is a project focused on simplifying work-time records and timesheet preparation. The repository contains evolving HTML versions together with an APK-oriented branch of the project, making it useful as both a browser-based utility and a foundation for mobile packaging.

### ✨ Project goals
- faster work-hours entry
- clear timesheet workflow
- browser-friendly interface
- mobile/APK-oriented variants
- portable HTML-based implementation
- iterative versions for continued development

### 📁 Repository
```text
TimeListe-Generator/
├── html/
│   ├── index v4.html
│   └── v5.html
└── Apk/
```

To test the web version, open the latest HTML file in a modern browser.
